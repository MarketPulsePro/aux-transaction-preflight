# Security and data boundary

AUX is an evaluation-grade synthetic-data service. Do not send real financial, personal, credential, regulated, or confidential data.

The public evaluation compares caller-supplied facts and history. It does not independently verify banks, beneficiaries, sanctions, corporate status, identity, or ownership, and it must not be used as production payment authorization.

Report potential security issues privately to the operator through the contact method published in the canonical AUX metadata. Do not place secrets, personal data, or exploit payloads in public issues.
